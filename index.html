학생이 과제를 제출하면 선생님의 구글 드라이브에 아래 구조로 폴더가 즉시 자동 생성되고 파일 및 링크가 차곡차곡 저장됩니다. 수업이 끝나면 관제탑의 [드라이브 수신 스위치] 버튼을 한 번만 누르면 외부 수신이 즉시 차단됩니다:

📁 화정도서관 AI 동화책 만들기
└── 📁 01번_김민우 작가/
├── 📁 1주차_주인공캐릭터/ (캐릭터 이미지 & 소개)
├── 📁 2-3주차_동화초안/ (Storybook 링크 & 초안 PDF)
└── 📁 4-5주차_최종동화책/ (최종 완성본 PDF & 낭독 대사)
* 웹 앱 URL을 등록하면 관제탑의 원클릭 셔터(ON/OFF) 및 학생 제출 자동 연동이 활성화됩니다.
🛠️ 원클릭 수신 차단 지원 스크립트 복사
  1. Google Drive에서 [새로 만들기 ➔ 더보기 ➔ Google Apps Script]를 엽니다.
  2. 기존 코드를 지우고 위 복사 버튼으로 복사한 스크립트를 붙여넣은 후 저장합니다.
  3. 우측 상단 [배포 ➔ 새 배포 ➔ 웹 앱] 선택 (액세스: '모든 사용자' 설정).
  4. 생성된 웹 앱 URL을 위 입력창에 붙여넣고 저장하면 연동 완료!
설정 없이도 브라우저 관제탑 내에서는 모든 파일이 실시간 정상 작동합니다.

15대 기기 실시간 동기화 (Firebase 연동)

GitHub Pages로 배포 시 서로 다른 노트북/태블릿 간 실시간 관제 연결

깃허브 배포 환경에서의 동작 안내

  • 학생 개인 자동 저장: 이 설정 없이도 학생들의 노트북/태블릿 안에서는 지난주 작성 내용이 100% 안전하게 자동 저장됩니다.
  • 구글 드라이브 제출: 선생님이 등록한 드라이브 웹 앱 URL은 Firebase 연동 시 학생 기기에도 자동 전달되어, 각 기기에서 바로 드라이브로 제출됩니다.
  • 선생님 관제탑 실시간 미러링: 학생이 타이핑하는 글자를 선생님 노트북 관제탑에 0.5초 만에 실시간으로 띄우려면 무료 Firebase 프로젝트 연동이 필요합니다.
* Firebase Console(무료) ➔ 프로젝트 설정 ➔ 웹 앱 추가 시 발급되는 firebaseConfig 객체입니다. 여기 저장한 값은 이 기기에만 적용됩니다.
💡 index.html 코드에 직접 넣는 가장 쉬운 방법

GitHub에 index.html을 올리기 전, 파일 내 GITHUB_FIREBASE_CONFIG 부분에 발급받은 키를 채워 넣고 커밋하시면 15명 학생 기기 전원에 실시간 동기화가 영구 활성화됩니다. (학생 기기까지 연결하려면 이 방법이 필요합니다. Firebase 콘솔에서 익명 로그인(Anonymous)과 Firestore를 켜 주세요.)
